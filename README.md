# IronTrack — Персональный трекер тренировок для Android

Современное автономное PWA-приложение для фиксации тренировок, отслеживания рабочих весов и силового прогресса в спортзале.

## Основные возможности

1. **Запись тренировок в реальном времени**:
   - Быстрый старт свободной тренировки или выбор из 5 готовых сплитов (Push, Pull, Legs, Full Body, Upper Body).
   - Подсказка рабочих весов с прошлой тренировки (`80 кг × 8`).
   - Быстрые кнопки регулировки веса (`+2.5`, `-2.5`).
   - Поддержка типов подходов: обычные, разминочные (W), дропсеты (D), отказные (F).
   - Защита от случайного закрытия: тренировка сохраняется в реальном времени.
2. **Умный таймер отдыха**:
   - Автоматический старт при отметке подхода галочкой.
   - Звуковые сигналы (3, 2, 1 и финальный гонг через Web Audio API).
   - Тактильный виброотклик на телефоне.
   - Не сбивается при блокировке экрана или переключении приложений.
3. **Каталог 40+ упражнений**:
   - Фильтрация по мышцам (Грудь, Спина, Ноги, Плечи, Бицепс, Трицепс, Пресс).
   - Подсчет личных рекордов (PR) по каждому упражнению.
4. **Инструменты зала**:
   - **Калькулятор блинов на гриф**: визуализирует олимпийские блины (25, 20, 15, 10, 5, 2.5, 1.25 кг) на втулке штанги.
   - **Калькулятор 1RM**: автоматический расчет максимального веса на 1 повторение по формуле Epley.
5. **Аналитика и графики**:
   - Интерактивный график силового прогресса (динамика роста веса во времени).
   - Подсчет суммарного тоннажа за тренировку и за всё время.
6. **100% Офлайн и безопасность**:
   - Данные сохраняются локально на вашем устройстве.
   - Работает в подвальных залах без интернета благодаря Service Worker.
   - Функция бэкапа: экспорт и импорт базы данных в один клик в JSON файл.

## Как установить на телефон Android

1. Запустите сервер на компьютере двойным кликом по файлу `start.bat` (или командой `python server.py`).
2. Подключите телефон к той же локальной сети Wi-Fi (или мобильной точке доступа с телефона).
3. В браузере Google Chrome на телефоне откройте адрес:
   ```
   http://10.41.53.131:8080
   ```
4. В правом верхнем углу Chrome нажмите **три точки** (меню).
5. Выберите пункт **«Установить приложение»** (или **«Добавить на главный экран»**).

## 📦 Сборка нативного `.apk` файла

В папке `android/` уже подготовлен полноценный нативный Android-проект:

### Способ 1: Сборка через Android Studio (самый простой)
1. Откройте папку `gym-tracker/android` в Android Studio.
2. В верхнем меню выберите **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
3. Готовый файл `app-debug.apk` появится в `android/app/build/outputs/apk/debug/`.
4. Скиньте файл на телефон и нажмите «Установить».

### Способ 2: Автоматическая сборка в облаке через GitHub Actions
1. Опубликуйте этот репозиторий на GitHub.
2. В репозитории уже настроен workflow [build-apk.yml](.github/workflows/build-apk.yml).
3. Перейдите во вкладку **Actions** -> выберите запуск -> скачайте готовый собранный `.apk` артефакт прямо на телефон!
